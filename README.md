# My Quatrix Mentorship Journey 🚀

Welcome to my repository! This is a collection of my study notes, practical assessments, and hands-on exercises from the **Quatrix Mentorship Program**. 

The goal of this repo is to document my learning journey, track my progress, and serve as a quick reference guide for anyone going through a similar program.

## 🧠 What I Learned

Throughout the Quatrix Mentorship Program, I gained practical experience in:
- Writing and debugging Bash and Python scripts
- Managing code with Git (branches, merges, and conflict resolution)
- Administering Linux systems and using the command line
- Designing and querying relational databases with SQL
- Setting up and configuring **Jenkins** and **Traccar** servers
- Using **Regular Expressions** for pattern matching and text processing
- Setting up CI/CD pipelines using Jenkins
